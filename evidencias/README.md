# Pasta de evidências

Autor: Bruno Liberato Girardi

O executor deve criar uma pasta por semana:

```text
evidencias/
  semana-01/
    resumo.md
    screenshots-ou-video/
    testes/
    decisoes/
  semana-02/
  semana-03/
  semana-04/
```

Cada pasta deve conter apenas evidências ligadas ao objetivo daquela semana. O registro principal continua no `REGISTRO-SEMANAL.md`; esta pasta guarda os artefatos que permitem reproduzir ou conferir a afirmação.

Não incluir segredos, tokens, dados pessoais desnecessários ou arquivos pesados sem necessidade.
