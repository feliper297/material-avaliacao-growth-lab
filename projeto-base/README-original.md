# Growth Lab — Product Design

Protótipo estático e responsivo para uma trilha de evolução profissional de 30 dias.

## O que está incluído

- Quatro semanas de conteúdos selecionados
- Links diretos para Figma, NN/g, Atlassian, MDN e OpenAI
- Prompt de tutor socrático integrado
- Link direto para o Study Mode do ChatGPT
- Mini testes por semana
- Registro de evidências
- Avaliação em seis dimensões
- Progresso salvo no navegador
- Exportação em JSON
- Relatório imprimível

## Como abrir

Abra `index.html` diretamente no navegador.

## Como publicar

Pode ser publicado sem alterações no:
- Vercel
- Netlify
- GitHub Pages
- Hostinger

Como é um protótipo sem backend, os dados ficam no `localStorage` do navegador utilizado.

## Evolução recomendada

Para uso real em equipe, a próxima versão pode incluir:
- login;
- banco de dados;
- upload de imagens;
- papéis de colaborador e gestor;
- comentários e aprovações;
- histórico de avaliações;
- notificações;
- painel comparativo entre semanas.
