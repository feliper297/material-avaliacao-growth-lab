# Instruções do pacote

Autor: Bruno Liberato Girardi

Leia `/README.md` antes de executar qualquer alteração. Este é um desafio duplo: construir o sistema Growth Lab e usar o sistema para demonstrar evolução semanal.

Regras rápidas:

- rode e registre o estado inicial de `projeto-base/` antes de editar;
- não trate o protótipo como solução final;
- não codifique antes de entregar problem framing, arquitetura, dados, estados e testes planejados;
- registre todos os usos relevantes de IA em `anexos/LOG-DE-IA.md`;
- valide diffs, testes, jornadas, CI/CD e deploy;
- não declare mock como real nem hipótese como causa confirmada;
- toda sexta-feira preencha o registro semanal e deixe a evidência pronta para auditoria.
